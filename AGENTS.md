# AGENTS.md

## Project Overview

This repository implements the official website for a custom programming language, built with **Astro + MDX**.

## Repository Structure and Deployment

- The official website implementation must be consolidated under `site/`.
- Deployment targets (for example, GitHub Pages) should be configured to publish only the `site/` directory.

## Content Voice Guidelines

- This programming language is developed by an individual and that should remain a core characteristic.
- Do not use collective wording such as "we" or "team" in site copy. Use first-person singular wording instead.

## Related Repositories

- The compiler implementation lives at `$HOME/Developer/Workspace/nue` and is currently private.
- A Playground implemented with **WASM + React** exists at `$HOME/Developer/Workspace/nue/web`.
