## Features

- Ruby-ish but deterministic grammar with strict `EOL` token rules.
- Explicit ownership with `move` and `copy`.
- Function arguments are borrow-by-default, with `own` and `inout` when needed.
- GC-less memory management with compiler-inferred lifetimes without annotations.
- Non storable view types: `ref`, `str`, and `slice`.
- Disjoint unions.
- Compile-time `const expr` evaluation for values and const generics.
- Protocols, associated types, and `some` opaque return types to keep abstractions precise.
