Welcome to the official Nue website project.

## Project layout

The deployable website is intentionally scoped to this directory:

```text
site/
  src/
    pages/
    layouts/
    styles/
```

Deploy only `site/` when publishing to platforms such as GitHub Pages.

## Local setup

```bash
cd site
npm install
npm run dev
```

## Related repositories

- Compiler (private): `$HOME/Developer/Workspace/nue`
- Playground (WASM + React): `$HOME/Developer/Workspace/nue/web`

## Community

The compiler is still private alpha. Follow updates from this site and keep feedback loops tight
between docs, language design, and Playground behavior.

## Roadmap

1. Stabilize language primitives and compile targets.
2. Expand Playground scenarios and diagnostics.
3. Open public previews once compiler APIs settle.
